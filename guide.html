    Topic 1: Mathematical preliminaries

    Chapter 0 and the first lecture supply the vocabulary every later question uses. Expect quick definition, set-calculation and counting questions.

    Sets

    • A set is unordered with no repeats: {7, 21, 57} = {57, 7, 21, 21}. A multiset counts repeats.
    • A ⊆ B: every element of A is in B. A ⊊ B (proper subset) also needs A ≠ B. For every set A, ∅ ⊆ A and A ⊆ A.
    • X = Y if and only if X ⊆ Y and Y ⊆ X.
    • Union, intersection, difference X − Y, complement X̄ = U − X relative to a universe U.
    • De Morgan: the complement of X ∪ Y is X̄ ∩ Ȳ; the complement of X ∩ Y is X̄ ∪ Ȳ.
    • Power set P(X), also written 2X in class: all subsets of X. |P(X)| = 2|X|. P(∅) = {∅} has one element.
    • Cardinality |S| counts top-level elements only: |{a, {a, b}, {a, {a, b, c}}}| = 3.
    From lecture: the class exercises, worked
    • ({8,9,14,7,5} ∪ {6,17,14,8}) ∩ {8,3,5} = {5, 8}
    • ({1,2,5} − {5,7,9}) ∪ ({5,7,9} − {1,2,5}) = {1, 2, 7, 9}
    • 2{5,4,2} − 2{4,5} = {{2}, {2,4}, {2,5}, {2,4,5}}: the subsets that contain 2
    • ∅ ∪ {∅} = {∅}; ∅ ∩ {∅} = ∅
    • {∅} ∩ {177, {∅}, {∅, {∅}}} = ∅, so “= {∅}” is false: ∅ itself is not an element of the second set
    • {(1,2), (x,x), (x,y), (y,1)} ⊆ {1,x,2,y} × {2,y,1,x}: true
    • ∅ ⊆ ∅ true; ∅ ∈ ∅ false; ∅ ∈ {∅} true; ∅ ⊆ {∅} true
    Watch the definition of N

    Sipser uses N = {1, 2, 3, …}. One lecture slide writes N = {0, 1, 2, …} and a later one {1, 2, 3, …}. If a question depends on it, use the definition the question gives.

    Tuples, functions and relations

    • A sequence or tuple is ordered and may repeat: (7, 21, 57) ≠ (57, 7, 21).
    • Cartesian product X × Y = {(x, y) | x ∈ X, y ∈ Y}; |X × Y| = |X|·|Y|. With X = {1, 2} and Y = {a, b, c}, X × Y has 6 pairs, each starting with 1 or 2.
    • A function f: D → R maps each input to exactly one output. One-to-one: distinct inputs give distinct outputs. Onto: every element of R is hit. Correspondence: both. There are |B||A| functions from A to B.
    • A function on X × Y can be shown as a table. The class example g: Z₄ × Z₄ → Z₄ is addition mod 4, so g(3, 2) = 1.
    • A binary relation on X and Y is a subset of X × Y; an n-ary relation is a subset of X₁ × … × Xₙ. A predicate is a function to {TRUE, FALSE}.
    • An equivalence relation is reflexive, symmetric and transitive.
    From lecture: scissors-paper-stone

    Beats = {(Scissors, Paper), (Paper, Stone), (Stone, Scissors)} ⊆ SPS × SPS. It is not reflexive, not symmetric and not transitive (Scissors beats Paper and Paper beats Stone, but Scissors does not beat Stone).

    Graphs

    • Degree of a node = number of edges at it. The sum of all degrees = 2|E|.
    • Path, simple path (no repeated nodes), connected, cycle, simple cycle (at least 3 nodes).
    • A tree is connected with no simple cycles; n nodes ⇒ n − 1 edges.
    • Directed graphs have indegree and outdegree; strongly connected means a directed path joins every ordered pair. A DFA’s state diagram is a labelled directed graph.

    Strings and languages

    • Alphabet Σ: a nonempty finite set of symbols. String: a finite sequence of symbols. Language: a set of strings.
    • |w| is the length; the empty string ε has |ε| = 0.
    • Concatenation xy; wk = w repeated k times, w0 = ε; reversal wR (abdR = dba).
    • Prefix x of w = xz, suffix z, substring: consecutive symbols. aaabc has 6 prefixes (ε through aaabc).
    • Shortlex order: by length, then dictionary order: ε, 0, 1, 00, 01, 10, 11, 000, …
    • A language is prefix-free if no member is a proper prefix of another member.
    From lecture: Σᵏ, Σ* and Σ⁺
    • Σk = all strings of length k over Σ; there are |Σ|k. For Σ = {a, b}, Σ² = {aa, ab, ba, bb} and Σ⁰ = {ε}.
    • Σ1 looks like Σ but differs in kind: Σ1 is a set of strings of length 1, Σ is a set of symbols.
    • Kleene closure Σ* = Σ⁰ ∪ Σ¹ ∪ Σ² ∪ …, all strings including ε. Σ⁺ = Σ¹ ∪ Σ² ∪ … = Σ* without ε.
    • ∅ is the language with no strings; {ε} is a language with one string.
    • A problem, in automata theory, means deciding whether a given string is in a given language.
    • Example: L = {0i1j | j ≥ i ≥ 0} is some 0s followed by at least as many 1s, so 0111 ∈ L but 001 ∉ L.

    Boolean logic

    • P → Q is false only when P is true and Q is false; it equals ¬P ∨ Q.
    • Contrapositive ¬Q → ¬P is equivalent to P → Q. The converse Q → P is not.
    • De Morgan: ¬(P ∧ Q) = ¬P ∨ ¬Q; ¬(P ∨ Q) = ¬P ∧ ¬Q.

    Recursive definitions

    From lecture

    A recursive definition of a set X has three parts:

    1. Basis: the starting elements (1 ∈ N).
    2. Recursive step: how to build new elements (if n ∈ N then s(n) ∈ N, s = successor).
    3. Closure: nothing is in X unless it comes from the basis by finitely many recursive steps.

    This generates 1, s(1), s(s(1)), … = 1, 2, 3, …. The Prolog maternal_ancestor example has the same shape: a base rule plus a recursive rule.

    Proofs and induction

    • Definition, theorem, lemma, corollary. “P if and only if Q” needs both P ⇒ Q and Q ⇒ P.
    • Construction: build the object (a 3-regular graph on every even n > 2 nodes).
    • Contradiction: assume the statement is false and derive the impossible (√2 is irrational). Pumping-lemma proofs work this way.
    • Induction: basis P(b); induction hypothesis P(k); inductive step P(k) ⇒ P(k + 1). Without a basis the proof is invalid.
    From lecture: induction examples to know
    • 1 + 2 + … + n = n(n + 1)/2, and 1² + 2² + … + n² = n(n + 1)(2n + 1)/6.
    • 3 | (4ⁿ − 1) for n ≥ 0. Basis: 4⁰ − 1 = 0 = 3·0. Step: 4ᵏ⁺¹ − 1 = 4(4ᵏ − 1) + 3 = 4(3z) + 3 = 3(4z + 1).
    • Every amount ≥ 8¢ from 3¢ and 5¢. Basis: 8 = 3 + 5 (also 9 = 3+3+3, 10 = 5+5). Step, by cases: if there is a 5¢ coin, replace it with two 3¢ (+1¢); otherwise there are at least three 3¢ coins, replace them with two 5¢ (+1¢).
    • Class exercise: every postage ≥ 12¢ from 3¢ and 7¢ (11¢ is impossible). Also: 43 divides 6ⁿ⁺² + 7²ⁿ⁺¹ for n ≥ 0.

    Topic 2: Finite automata

    A DFA reads its input once, left to right, with fixed finite memory (its current state), and accepts if it ends in an accept state. DFAs recognize exactly the regular languages.

    Formal definition and computation

    A DFA is a 5-tuple M = (Q, Σ, δ, q₀, F):

    PartMeaningRemember
    QStatesFinite
    ΣInput alphabetFinite
    δδ: Q × Σ → QExactly one move per (state, symbol); no ε-moves
    q₀Start stateExactly one
    FAccept statesF ⊆ Q; F = ∅ gives L(M) = ∅

    M accepts w = w₁…wₙ if there are states r₀, …, rₙ with r₀ = q₀, rᵢ₊₁ = δ(rᵢ, wᵢ₊₁), and rₙ ∈ F. L(M) is the language M recognizes; M accepts ε exactly when q₀ ∈ F. A missing arrow is not allowed in a DFA: add a dead state that loops on every symbol.

    DFA minimization From lecture

    Not in the assigned Sipser pages, but covered in two lectures. Every regular language has a unique minimum-state DFA up to renaming states (isomorphism), so two DFAs are equivalent exactly when their minimized versions match.

    1. Remove states that cannot be reached from the start state.
    2. Merge equivalent states.

    States p and q are equivalent if for every string w, reading w from p ends in an accept state exactly when reading w from q does. Otherwise they are distinguishable. The table-filling (Myhill–Nerode) method finds every distinguishable pair:

    • Basis: mark {p, q} when exactly one of them is accepting.
    • Inductive step: mark {p, q} when, for some symbol a, the pair {δ(p, a), δ(q, a)} is already marked.
    • Repeat until nothing changes. Unmarked pairs are equivalent; merge them.

    Worked example (class). Accept states A and C:

    Stateon 0on 1
    → A (accept)BC
    BAD
    C (accept)DA
    DCB

    Basis marks every accepting/non-accepting pair: {A,B}, {A,D}, {B,C}, {C,D}. Check {A,C}: on 0 they go to {B,D}, on 1 to {C,A}; neither pair is marked. Check {B,D}: on 0 → {A,C}, on 1 → {D,B}; unmarked. Nothing new gets marked, so A ≡ C and B ≡ D. The minimal DFA has 2 states and accepts strings with an even number of 0s.

    Larger class example. States a–h, start a, accept c:

    Stateabc*defgh
    on 0bgachcgg
    on 1fccgfgec

    Result: [a, e], [b, h], [d, f], [c], [g], five states. d is unreachable from a, so step 1 removes it anyway. a and b are distinguished by the string 1 (a → f rejects, b → c accepts).

    Topic 3: NFAs and regular expressions

    NFAs

    An NFA may have zero, one or many moves on a symbol, plus ε-moves, and accepts if any branch ends in an accept state. Think of parallel threads, a tree of branches, or a machine that always guesses right.

    FeatureDFANFA
    δQ × Σ → QQ × Σ_ε → P(Q)
    Moves per (state, symbol)Exactly oneZero, one or many
    ε-arrowsNoYes
    No move availableImpossibleThat branch dies
    Complement by swapping FWorksDoes not work

    Acceptance: w = y₁…yₘ with each yᵢ ∈ Σ_ε, and states r₀ = q₀, rᵢ₊₁ ∈ δ(rᵢ, yᵢ₊₁), rₘ ∈ F. Every DFA is already an NFA. NFAs can be much smaller: “third symbol from the end is 1” needs 4 NFA states but 8 DFA states (generally k + 1 versus 2k).

    NFA → DFA: subset construction

    • ε-closure E(R): states reachable from R by zero or more ε-arrows.
    • DFA states: subsets of Q (at most 2k). Start: E({q₀}).
    • δ′(R, a) = E(union of δ(r, a) over r ∈ R).
    • Accept: every subset containing at least one NFA accept state. ∅ is the dead state.

    Example: NFA for strings ending in 01 (p loops on 0, 1; p → q on 0; q → r on 1; accept r) gives reachable subsets {p}, {p, q}, {p, r}, with {p, r} accepting. Corollary 1.40: a language is regular if and only if some NFA recognizes it.

    A₁*New start state that is accepting, ε to the old start; ε from accept states back to the old start

    Regex → NFA (Lemma 1.55, p. 67): a is two states with one a-arrow; ε is one accepting state; ∅ is one non-accepting state; then use the union, concatenation and star constructions. For (ab ∪ a)*, build a and b, concatenate, union with a, then star last.

    DFA → regex via GNFAs

    A GNFA labels arrows with regular expressions and is put in special form: the start state has only outgoing arrows; one accept state, different from the start, has only incoming arrows; every other pair has one arrow each way (∅ for “none”).

    1. From a k-state DFA, add a new start (ε to the old start) and a new accept state (ε from old accept states): k + 2 states.
    2. Rip out states one at a time; the last label is the answer.
    new label(qᵢ → qⱼ) = (R₁)(R₂)*(R₃) ∪ (R₄)

    R₁: qᵢ → q_rip, R₂: q_rip’s self-loop, R₃: q_rip → qⱼ, R₄: the direct arrow qᵢ → qⱼ. Example: state 1 (start) loops on a, goes to 2 on b; state 2 (accept) loops on a, b. Rip 2: b(a ∪ b)*. Rip 1: a*b(a ∪ b)*. A different rip order gives an equivalent regex that may look different.

    Lexical analysis From lecture

    The lexical analyzer is the first phase of a compiler: it reads characters and outputs tokens for the parser. Tools such as grep, lex, sed and awk turn a regex into a DFA to scan text.

    • Shorthand: r⁺ = rr*, r* = r⁺ | ε, r? = r | ε, [abc] = a | b | c, [a–z] = a | … | z.

    Topic 4: Pumping lemma and CFGs

    The pumping lemma

    If A is regular, there is a number p (the pumping length) such that every s ∈ A with |s| ≥ p can be split s = xyz with:

    1. xyiz ∈ A for every i ≥ 0;
    2. |y| > 0;
    3. |xy| ≤ p.
    Errata on one class slide

    The first pumping-lemma slide in the lecture states “|xy| > p” and “for any i > 0”. Those are typos. The correct conditions are |xy| ≤ p and i ≥ 0, as in Sipser and the later slide. Pumping down (i = 0) is often the key move.

    Why it is true. A DFA with p states reading at least p symbols visits at least p + 1 states, so by the pigeonhole principle some state repeats within the first p symbols. The loop between visits is y.

    It is a necessary condition only: use it to prove a language is not regular, never to prove one is.

    3YouPick s ∈ A with |s| ≥ p, written in terms of p
    4AdversaryPicks any split with |y| > 0 and |xy| ≤ p
    5YouShow some i gives xyiz ∉ A, for every allowed split

    • The lecture’s first proof that {0ⁱ1ⁱ} is not regular uses three cases (y all 0s, all 1s, or mixed). With |xy| ≤ p only the first case can happen, which is why the later slide is shorter.
    • The class sometimes writes the split as uvw instead of xyz: same thing.
    • Closure trick: B = {equal 0s and 1s}. If B were regular, B ∩ 0*1* = {0ⁿ1ⁿ} would be regular. Contradiction.
    • Intuition can be wrong: C = {w : equally many 01 and 10 substrings} looks like counting but is regular (they are equal exactly when w is empty or starts and ends with the same symbol). “I couldn’t find a DFA” is not a proof.

    Also regular: any finite language (such as {0ⁿ1ⁿ | n ≤ 100}), 0*1*, and counting mod k. Common mistakes: choosing p or the split yourself, choosing s ∉ A or shorter than p, and forgetting i = 0.

    Context-free grammars

    A CFG is a 4-tuple. Sipser writes (V, Σ, R, S); the lectures write (V, T, P, S): variables, terminals, productions, start variable. Every rule is A → α with A a single variable and α ∈ (V ∪ T)*. A → α₁ | α₂ | … is shorthand for several rules.

    • α ⇒ β: one rule applied once. α ⇒* β: zero or more steps.
    • L(G) = {w ∈ T* | S ⇒* w}: strings of terminals only, derived from S. Such a language is context-free.
    • CFGs began as a way to describe natural language: ⟨sentence⟩ → ⟨noun phrase⟩ ⟨verb phrase⟩.

    Designing grammars, ambiguity, CNF

    • Union: S → S₁ | S₂. From a DFA: Rᵢ → aRⱼ when δ(qᵢ, a) = qⱼ, Rᵢ → ε for accept states, start R₀. So every regular language is context-free. Linked parts: R → uRv. Nesting: let a variable appear inside its own rules.
    • A grammar is ambiguous if some string has two parse trees, equivalently two leftmost derivations. The class grammar E → E + E | E * E | (E) | id is ambiguous: id + id * id groups two ways. Two different derivations alone prove nothing.
    • A language is inherently ambiguous if every grammar for it is ambiguous, e.g. {aⁱbʲcᵏ | i = j or j = k}.
    • Chomsky normal form (A → BC or A → a, plus S → ε) starts around page 107 and is not in the lecture slides. Low priority.
